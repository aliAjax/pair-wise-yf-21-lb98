# hxyfront-62009 地毯修复 · 按比例定损台

给手工地毯修复工作室使用的纹样与修复档案：把静态档案页升级为按真实比例定损的工作台。

## 业务流程

1. **选中地毯 → 录入比例**：分别填写纬向（水平）、经向（竖直）的「每厘米像素值 px/cm」。手工地毯经纬密度不同，两个方向必须分开录入。
2. **纹样图上圈选破损区域**：在图上拖动即可，坐标按纹样图原始像素存储，缩放显示不影响计算。
3. **自动算尺寸**：纬宽 = 水平像素 ÷ 纬向 px/cm，经长 = 竖直像素 ÷ 经向 px/cm，并给出面积、周长和**所需补线长度**。
4. **另一名师傅复核**：进入补线前必须复核，且复核人不能与测量人为同一人；复核不通过可退回待测。复核通过后方可开工、登记完工。
5. **清洗缩水重新定标**：比例变化时
   - 未复核（待测 / 已测待复核）区域：尺寸标记**失效并退回待测**，圈选框保留，按新比例重测；
   - 已复核但未开工区域：**暂停**，旧尺寸划线保留作对照，重测 + 再次复核后才能开工；
   - 补线中、已完工区域：记录原样保留（已完工不可删除）。
6. 顶部进度汇总与左侧按产地筛选实时联动；所有数据写入浏览器 localStorage，关闭页面再回来仍能看到每块区域、尺寸与复核人。

## 三层结构（规则 / 存档 / 页面分开维护）

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 尺寸规则（纯函数，无 DOM/React） | `src/rules/measurement.ts` | 像素↔厘米换算、补线公式、复核人规则、状态流转、缩水失效规则、汇总。核算参数（耗线系数、最小圈选尺寸等）集中在 `MEASUREMENT_RULES` |
| 本地存档 | `src/storage/archiveStore.ts` | localStorage 读写、版本号与迁移、内置示例档案（内置 SVG 纹样图） |
| 页面 | `src/App.tsx`、`src/components/*`、`src/state/useArchive.ts` | 圈选交互、录入表单、复核操作、筛选与汇总 |

调整核算口径只需改规则层；更换存储实现只需改存档层，页面通过 `useArchive` hook 调用，不直接碰规则之外的数据结构。
