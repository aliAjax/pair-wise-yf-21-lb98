# hxyfront-62009 地毯修复纹样档案 · 按比例定损台

源提示词编号：2

给手工地毯修复工作室使用的纹样与修复档案前端项目。档案页已升级为**按比例定损台**：

- 选中地毯后录入**经向 / 纬向每厘米像素值**标定比例；
- 在纹样图上**拖框圈出破损区域**，自动算出长宽、面积和所需补线长度（按结密度估算）；
- 进入补线前必须由**另一名师傅复核**尺寸（复核人不能是测量人），也可复核退回；
- 清洗缩水导致**比例变化**时：未复核区域尺寸标记失效并退回待测；已复核未开工的区域暂停；修复中与已完工记录保留；
- 暂停区域可按新比例复测，重新走复核流程；
- **按产地筛选**与**进度汇总**（各状态数量、完工率、待用补线合计）随操作实时更新；
- 所有区域、尺寸、复核人、流转记录都存入 localStorage，**关闭页面再回来仍在**。

## 技术栈

React + Vite + TypeScript

## 目录结构（规则 / 存档 / 页面分开维护）

```
src/
  rules/       尺寸规则：types.ts（领域类型）、measure.ts（比例换算与补线估算）、workflow.ts（工序流转与复核规则）
  store/       本地存档：archive.ts（localStorage 读写与演示数据）
  components/  页面组件：PatternCanvas（纹样图与圈选）、ScalePanel（比例标定）、RegionDetail（区域详情与操作）
  App.tsx      页面装配与状态管理
```

调整补线估算口径（每结用线、损耗率）只需改 `src/rules/measure.ts`；
调整工序规则（复核、缩水后的状态去向）只需改 `src/rules/workflow.ts`。
